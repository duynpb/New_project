# Deutschly

A premium Material 3 Android learning companion for Vietnamese learners of German, from A1 through C1.

## Included experience

- Personalized daily dashboard with progress, streaks, XP, lesson continuation, and a word of the day.
- Android-native five-destination navigation for learning, practice, spaced repetition, and profile views.
- Vocabulary, grammar, listening, speaking, writing, and Goethe/telc exam practice entry points.
- Warm notebook-inspired palette, dark-mode support, edge-to-edge rendering, and touch-friendly Material 3 components.

## Build

```sh
gradle :app:assembleDebug
```
